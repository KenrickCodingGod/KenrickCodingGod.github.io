# Onderbouwing ontwerp

## Gebruikersscenario 1

Een recruiter bezoekt mijn portfolio om snel te bekijken welke projecten ik heb gemaakt en welke vaardigheden ik daarbij heb gebruikt.

## Gebruikersscenario 2

Een bezoeker komt op mijn portfolio om te zien wie ik ben, welke opleiding ik volg en wat mijn interesses en vaardigheden zijn.

## Ontwerpkeuze 1 - Navigatie bovenaan

Ik heb de navigatie bovenaan elke pagina geplaatst met de opties Whoami, Projecten en Blog. Hierdoor kan een recruiter of andere bezoeker snel naar de gewenste pagina gaan zonder lang te hoeven zoeken.

## Ontwerpkeuze 2 - Duidelijke paginastructuur

Ik heb mijn portfolio verdeeld over drie aparte pagina's: Whoami, Projecten en Blog. Hierdoor kan een bezoeker sneller de informatie vinden die hij zoekt. Een recruiter kan bijvoorbeeld direct naar de projectenpagina gaan zonder eerst andere informatie te hoeven lezen.

## Ontwerpkeuze 3 - Responsive layout

Ik heb de layout responsive gemaakt zodat de website bruikbaar blijft op verschillende schermgroottes. Op kleinere schermen wordt de navigatie onder elkaar weergegeven, zodat de links goed leesbaar en klikbaar blijven.

## Bron

Voor de responsive layout heb ik informatie gebruikt van MDN over responsive web design en media queries. Media queries maken het mogelijk om de layout aan te passen aan verschillende schermgroottes.
